# Privacy Policy — FlowLink Proxy

**Последнее обновление:** 16 июля 2026 г.

## Обзор

FlowLink Proxy — это расширение для браузера, которое управляет локальным SOCKS5-прокси сервером. Расширение работает **исключительно на вашем устройстве** и не передаёт данные третьим лицам.

## Какие данные обрабатываются

| Данные | Где хранятся | Зачем |
|--------|-------------|-------|
| Адреса и порты прокси | `config.json` на диске | Подключение к прокси-серверу |
| Логины и пароли прокси | `config.json` (зашифрованы AES-GCM) | Аутентификация на прокси-сервере |
| Маски адресов (домены/IP) | `config.json` | Маршрутизация трафика |
| Мастер-ключ шифрования | `.flowlink.key` на диске | Дешифрование паролей прокси |
| Соль деривации ключа | `.flowlink.salt` на диске | Генерация ключа из мастер-пароля |
| Настройки автозапуска | `.flowlink-settings` на диске | Путь к браузеру и режим автозапуска |
| Фактические порты сервера | `.flowlink-port` на диске | Отладка, логи, внешние инструменты |
| Логи работы сервера | `logs/` на диске | Диагностика: время запуска/остановки, статус подключений к прокси, ошибки маршрутизации. Содержимое трафика не логируется |
| Состояние вкл/выкл | `chrome.storage.local` | Запоминание состояния |
| Порт API сервера | `chrome.storage.local` | Связь с локальным бэкендом |

## Что НЕ делает расширение

- **Не собирает** статистику, аналитику, телеметрию
- **Не отправляет** данные на внешние серверы (кроме GitHub API — см. ниже)
- **Не отслеживает** историю просмотров
- **Не показывает** рекламу
- **Не продаёт** и не передаёт данные третьим лицам

## Маршрутизация трафика

FlowLink Proxy направляет ваш трафик через прокси-серверы, которые вы настраиваете самостоятельно. Эти серверы находятся под вашим контролем (или контролем вашего прокси-провайдера). FlowLink Proxy:

- **Не имеет доступа** к вашим прокси-серверам — только передаёт им трафик по вашей конфигурации
- **Не хранит** и не анализирует содержимое передаваемого трафика
- **Не выбирает** прокси за вас — все прокси-серверы добавляются и настраиваются только вами вручную
- Работает как шлюз: принимает трафик от браузера и, в зависимости от масок, направляет его либо напрямую, либо через указанный вами прокси-сервер

> **Важно:** ответственность за выбор прокси-серверов и безопасность передаваемого через них трафика лежит на вас. FlowLink Proxy не контролирует работу внешних прокси-серверов и не может гарантировать их безопасность.

## Сетевые запросы

Расширение выполняет только два типа запросов:

1. **Локальный бэкенд** (`127.0.0.1`) — управление прокси-сервером. Все данные остаются на вашем устройстве.

2. **GitHub API** (`api.github.com`) — проверка наличия обновлений. Запрашивается только публичная информация о версиях релизов. Данные о пользователе не передаются. При обращении к GitHub API ваш IP-адрес обрабатывается серверами GitHub в соответствии с их политикой конфиденциальности.

## Хранение данных

Все данные хранятся **только на вашем устройстве** в папке данных приложения (`~/.FlowHack/FlowLink Proxy/` на Linux/macOS, `%APPDATA%\FlowHack\FlowLink Proxy\` на Windows):
- `config.json` — конфигурация прокси и масок (пароли зашифрованы AES-GCM)
- `.flowlink.key` — мастер-ключ шифрования
- `.flowlink.salt` — соль для вывода ключа
- `.flowlink-settings` — настройки автозапуска
- `.flowlink-port` — фактические порты API и прокси
- `logs/` — логи работы сервера
- Настройки расширения — в `chrome.storage.local` (изолированное хранилище браузера)

При удалении расширения его настройки (`chrome.storage.local`) удаляются автоматически. Файлы бэкенда (конфигурация, ключи шифрования, логи) хранятся отдельно в папке данных — см. раздел «Хранение данных». Для полной очистки удалите папку данных вручную (инструкция в README).

## Шифрование

Пароли прокси-серверов шифруются алгоритмом AES-GCM (256-бит). Ключ шифрования уникален для каждого устройства и генерируется из мастер-пароля.

## Безопасность

- Расширение не использует `webRequest` для перехвата трафика
- Расширение не инжектит скрипты на страницы
- Минимальный набор разрешений: `activeTab`, `alarms`, `storage`
- Доступ только к `127.0.0.1` (localhost) и `api.github.com`

## Дети

Расширение не предназначено для лиц младше 13 лет и не собирает данные детей.
