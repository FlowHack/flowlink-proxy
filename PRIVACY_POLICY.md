# Privacy Policy — FlowLink Proxy

**Последнее обновление:** 9 июля 2026 г.

## Обзор

FlowLink Proxy — это расширение для браузера, которое управляет локальным SOCKS5-прокси сервером. Расширение работает **исключительно на вашем устройстве** и не передаёт данные третьим лицам.

## Какие данные обрабатываются

| Данные | Где хранятся | Зачем |
|--------|-------------|-------|
| Адреса и порты прокси | `config.json` на диске | Подключение к прокси-серверу |
| Логины и пароли прокси | `config.json` (зашифрованы AES-GCM) | Аутентификация на прокси-сервере |
| Маски адресов (домены/IP) | `config.json` | Маршрутизация трафика |
| Состояние вкл/выкл | `chrome.storage.local` | Запоминание состояния |
| Порт API сервера | `chrome.storage.local` | Связь с локальным бэкендом |

## Что НЕ делает расширение

- **Не собирает** статистику, аналитику, телеметрию
- **Не отправляет** данные на внешние серверы (кроме GitHub API — см. ниже)
- **Не отслеживает** историю просмотров
- **Не показывает** рекламу
- **Не продаёт** и не передаёт данные третьим лицам

## Сетевые запросы

Расширение выполняет только два типа запросов:

1. **Локальный бэкенд** (`127.0.0.1`) — управление прокси-сервером. Все данные остаются на вашем устройстве.

2. **GitHub API** (`api.github.com`) — проверка наличия обновлений. Запрашивается только публичная информация о версиях релизов. Данные о пользователе не передаются.

## Хранение данных

Все данные хранятся **только на вашем устройстве**:
- Конфигурация — в файле `config.json` в папке данных расширения
- Настройки — в `chrome.storage.local` (изолированное хранилище браузера)

При удалении расширения все данные удаляются автоматически.

## Шифрование

Пароли прокси-серверов шифруются алгоритмом AES-GCM (256-бит). Ключ шифрования уникален для каждого устройства и генерируется из мастер-пароля.

## Безопасность

- Расширение не использует `webRequest` для перехвата трафика
- Расширение не инжектит скрипты на страницы
- Минимальный набор разрешений: `activeTab`, `storage`
- Доступ только к `127.0.0.1` (localhost) и `api.github.com`

## Дети

Расширение не предназначено для лиц младше 13 лет и не собирает данные детей.

## Изменения

При обновлении этой политики версия обновляется в дате «Последнее обновление» в начале файла.
