FlowLink Proxy — Установка расширения

Бэкенд запущен, но расширение Chrome не подключено. Выполните следующие шаги:

1 Откройте Chrome и перейдите на страницу расширения:
github.com/FlowHack/flowlink-proxy/releases
2 Установите расширение одним из способов:
  • Вручную (CRX): скачайте FlowLink-Proxy-vX.X.X.crx со страницы релизов и перетащите на chrome://extensions.
  • Из исходников: включите режим разработчика, нажмите «Загрузить распакованное расширение» и выберите папку extension.
Примечание: после установки расширения вручную нажмите «Обновить» (круглая стрелка) на странице chrome://extensions, чтобы применить изменения.

Подробная справка по настройке доступна в расширении: нажмите на иконку FlowLink Proxy → «Помощь».

Примечание: Возможно, потребуется VPN или прокси для доступа к GitHub (для пользователей в России).
