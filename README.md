# FlowLink Proxy

Управление SOCKS5-прокси с масками адресов. Расширение для Chrome (Manifest V3).

## Установка

1. Открой `chrome://extensions`
2. Включи **Режим разработчика**
3. Нажми **Загрузить распакованное расширение**
4. Выбери папку `src/`

## Использование

1. Нажми на иконку расширения → откроется popup
2. Нажми **+ Добавить прокси** → заполни IP, порт, логин и пароль (все поля обязательны)
3. После добавления прокси по умолчанию включён
4. Нажми на IP прокси → откроется управление **масками** (регулярные выражения для URL)
5. Маски определяют, какие сайты направляются через этот прокси

### Возможности

- **Пинг всех** — проверяет доступность всех прокси (последовательно, 5 сек таймаут)
- **Глобальный переключатель** — мгновенно отключает/включает всю маршрутизацию
- **Health Check** — фоновая проверка каждые 30 секунд, автоматическая блокировка недоступных прокси
- **Failover** — при недоступности прокси трафик блокируется (Strict Proxy Policy), при восстановлении разблокируется
- **Уведомления** — при блокировке/восстановлении прокси

## Безопасность

- **Мастер-ключ** генерируется при первом запуске, хранится в `chrome.storage.local` в формате JWK
- Username/password шифруются **AES-GCM 256** с уникальным 12-байтным IV
- Расшифровка только в Service Worker — пароли никогда не покидают защищённый контекст
- CSP: `script-src 'self'; object-src 'self'` — запрещены eval, unsafe-inline, unsafe-eval
- PAC-скрипт генерируется через `JSON.stringify` — защита от XSS-инъекций
- Нарушение Strict Proxy Policy: при недоступности прокси возвращается `PROXY 0.0.0.0:9` (блокировка)
